Behind the scenes

One page became a whole system.

Ten milestones, four themes, one intense week. Here's the walk from a single glitching headline to the site you're on right now.

The theme switcher above still works here — dark is where it started, Draft is where it ended up (for now).

01

The spark.

It started with a single page, running in dark. Just enough to test one thing: a text animation that glitches into color when you hover it. If that felt right, everything else could be built around it.

02

Proving the basics.

Before building anything ambitious, I set myself a smaller test: could I still put together a proper multi-page site from scratch? A couple of bare sections were enough to answer that — yes.

03

Giving it a voice.

With the structure standing, I added Who I am — a page to introduce myself beyond a résumé, in the same visual language as the rest of the site.

04

Rounding it out.

Portfolio and a way to reach me came next, closing the loop: land, understand who I am, see the work, get in touch.

05

A second skin.

Then came the itch to push further — a Light theme, mostly as an excuse to test different typography against the very same layout.

06

Not disruptive enough.

Grape followed: a bold, single-color canvas. It looked good, but it didn't feel different enough. I wanted a fourth theme that broke the pattern harder — without breaking the system holding it together.

07

The one that broke the mold.

That became Draft: a sketched, hand-drawn skin. It looks nothing like the other three, but underneath it runs on the exact same structure — more consistent than it has any right to look.

08

Bringing the home to life.

From there it became a habit — hunting down small components worth adding to the home page, and making each one interactive instead of static.

09

An action to play with.

The last idea: giving the Draft pages an actual drawing tool, so the sketch look wasn't just decoration — you could draw on it too.

10

One week later.

Many small iterations later, across about a week, this is where it landed — for now.

Built with.

  • HTML + CSS + JS — no framework, no build step, everything served as static files
  • GSAP + SplitText (CDN) — the engine behind the glitch effect on headings
  • Drawably (CDN) — hand-drawn UI components for the Draft theme
  • GitHub + GitHub Actions + Vercel — automatic deploy to GitHub Pages, with Vercel handling the custom domain for faster deploys
  • Node.js (tools/build-vault.mjs) — local script that encrypts the vault content
